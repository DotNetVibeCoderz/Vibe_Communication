# Rumble.Net documentation

Rumble.Net is a Mumble voice chat SDK for .NET 10. Its networking, cryptography and audio pipeline are written in Rust.

| Guide | Read it when you want to… |
|---|---|
| [Getting started](getting-started.md) | Install, connect to a server and send your first message and voice |
| [Architecture](architecture.md) | Understand how the Rust core, the C ABI and the .NET layer fit together |
| [Client API](client-api.md) | Use channels, users, messages, events, moderation and queries |
| [Audio](audio.md) | Choose an audio mode, set up transmit modes, filters and positional audio, or use the Opus codec directly |
| [Bots and plugins](bots-and-plugins.md) | Build command bots, AI chat bots, hosted services and reusable plugins |
| [Security](security.md) | Understand TLS verification, certificate identities, pinning and UDP encryption |
| [Native C API](native-c-api.md) | Call the core from C, C++ or any language with an FFI |
| [Game engines](game-engines.md) | Add voice chat to Unity or Unreal Engine |
| [Samples](samples.md) | Run RumbleApp and RumbleGallery |
| [Testing and benchmarks](testing-and-benchmarks.md) | Run the test suites, the mock server, benchmarks and the latency probe |
| [Building and packaging](building-and-packaging.md) | Build native binaries for each platform and publish the NuGet packages |
| [Troubleshooting](troubleshooting.md) | Fix connection, audio and native loading problems |
